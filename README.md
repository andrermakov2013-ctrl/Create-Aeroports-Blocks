# Create: Aeroports Blocks

A Minecraft 1.21.1 NeoForge mod for building detailed airports with Create-inspired systems.

## Development target

- Minecraft: 1.21.1
- NeoForge: 21.1.266
- Create: 6.0.10+
- Java: 21

## Current prototype

- Runway asphalt block (uses the vanilla gray-concrete texture for now).
- Dedicated creative tab with Russian and English names.
- GitHub Actions build workflow.

## Planned features

- Runway and taxiway surfaces, markings and lights.
- Terminal and hangar blocks.
- Baggage handling using Create belts and other kinetic components.
- Animated passenger boarding bridges with extendable accordion sections.

The project is in early development. Features listed as planned are not implemented yet.

## Build

Run:

```bash
gradle build
```

The mod JAR is generated in `build/libs`.
